# AI-Based Web Application Firewall (AI-WAF)

This project implements an AI-powered Web Application Firewall using Machine Learning and an Adaptive Attack Mutation Engine (AAME).

## Features
- SQL Injection Detection
- XSS Detection
- Self-learning Mutation Engine
- Automatic Model Retraining

## Tech Stack
- Python
- FastAPI
- Scikit-learn
